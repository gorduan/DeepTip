# DeepTip knowledge pack

For chat assistants and local front-ends that cannot read your project's files. Generated by `tools/harness.mjs` from [`../source.json`](../source.json); the limits of each product are in the [table](../README.md#chat-assistants-and-local-front-ends).

1. Paste [`instructions.md`](instructions.md) (at most 8,000 characters, a condensed `SKILL.md`) into the product's instructions field. For small local models use [`system-prompt.md`](system-prompt.md) instead (under 1,000 tokens).
2. Upload the core files. They are in `skill/deeptip/references/` of the repository and in `DeepTip-skill-1.1.0.zip` of the [releases](https://github.com/gorduan/DeepTip/releases):

| Order | File in `references/` | Why |
|---|---|---|
| 1 | `SPEC.md` | the contract: data, behaviour, placement, input, accessibility, options |
| 2 | `docs/algorithms.md` | every algorithm of the reference as language-neutral pseudo-code |
| 3 | `frameworks/<name>/README.md` | the guide of your framework, only that one |
| 4 | `schema/deeptip.schema.json` | the JSON Schema of a glossary file |
| 5 | `glossary/core/<locale>.json` | optional: DeepTip's own help texts, good examples of entries |
| 6 | `test/cases/*.json` | optional: the parity cases, when you port DeepTip to a new system |
| 7 | `frameworks/web/deeptip.js` | optional: the reference runtime, when you build for the web |

3. Where a product accepts Agent Skills (a folder or zip with `SKILL.md`), upload the whole skill instead: `DeepTip-skill-1.1.0.zip` holds the folder `deeptip/`.

`node tools/install.mjs <folder> --harness <product> --framework <name>` writes the text, the core files and your framework's guide into `<folder>/deeptip-<product>/`, ready to upload. `--list` shows the product names.
